# 转向架 · 交互式结构解剖

一套可离线打开的动车组动力转向架三维结构演示。以所提供的 `3d 车轮底盘模型.glb` 和两张转向架结构图为构型参考，重制为可交互的分件模型，聚焦七大总成的空间位置、单件拆解与作用讲解。轴箱与一系悬挂按参考图布置在车轮外侧的轴端，侧梁也随之外移；一系悬挂由内/外圆簧组、轴箱定位装置和垂向减振器组成。二系悬挂以空气弹簧作为车体支撑装置，并配置垂向减振器、横向减振器、抗蛇行减振器、抗侧滚装置、横向止挡和牵引装置。构架按 CRH2 型结构重制为两根侧梁、两根横梁和两根纵向连接梁组成的中央矩形框，并布置空气弹簧支承座、制动吊座、定位臂、增压缸安装座、垂向止挡、电机/齿轮箱吊座。驱动装置采用架悬式：每台转向架配置两台牵引电机，分别对应两组轮对；电机固装构架，经弹性联轴器、空心轴、传动销和连杆驱动轮对，属于簧上质量。模型纵向略微拉长，以改善整体比例；同时加入弧形侧梁、四角圆形端座、大直径扁平空气弹簧、高度调整阀和踏面清扫装置等细节。

## 快速开始

直接双击 `index.html` 即可打开，无需安装依赖、无需构建、无需联网。

也可以通过本地服务器访问：

```bash
python -m http.server 8000
```

然后打开 <http://127.0.0.1:8000>。

> 需要浏览器支持 WebGL2，建议使用最新版 Chrome、Edge 或 Safari。

## 交互

- **拖拽**：旋转视角；**滚轮**：缩放；触屏设备支持单指旋转。
- **点击模型上的编号、定位点或左侧索引**：进入单件拆解，只保留该总成为实体，其余部分淡化为结构参照。
- **装配 / 分解**：在整车视图与七件全分解视图之间切换。
- **视角按钮**：等轴、侧视、端视、俯视。
- **自转、缩放、复位、全屏**：位于模型下方的控制条。
- **Esc**：退出单件拆解，返回全车视图。
- 空白处点击也可返回整车视图。

## 七大总成

| 编号 | 总成 | 核心作用 |
| --- | --- | --- |
| 01 | 轮对 | 承载、传力、滚行、导向 |
| 02 | 轴箱装置 | 降低阻力、化滚为平 |
| 03 | 一系悬挂装置 | 轴箱定位、轮对缓冲、构架减振 |
| 04 | 构架 | 联系骨架、安装基础 |
| 05 | 二系悬挂装置 | 支撑车体、缓冲减振、定位 |
| 06 | 基础制动装置 | 产生、放大、传递制动力 |
| 07 | 电机驱动装置 | 能量转化、产生驱动力矩 |

每个总成都配有作用详解、结构组成、力/能流路径和工程提示。

## 技术实现

- 原生 **WebGL2** 实时渲染，不使用 Three.js 或任何外部依赖。
- 自研程序化几何构建：车轮踏面、车轴、构架侧梁、螺旋弹簧、空气弹簧、制动盘、牵引电机与齿轮箱均由代码生成。
- 金属度/粗糙度近似 PBR、方向光阴影贴图、环境渐变、地面网格与接触阴影。
- **GPU 拾取**：离屏帧缓冲读取像素，实现模型分件点击。
- 自研轨道相机、分件爆炸动画与标签投影，全部离线可用。
- 响应式布局：桌面三栏、窄屏图标索引、手机底部部件条与详情抽屉。
